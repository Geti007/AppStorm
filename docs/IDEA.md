# App idea (demo run, 2026-10-14)

Glassful: a simple water tracker.

The owner asked to watch the factory work live and did not name an idea, so
this demo uses a small one that finishes quickly.

- Set a daily water goal on first launch.
- Log a drink in one tap with a few common glass sizes, or type any amount.
- See today's progress toward the goal, and undo a mistake.
- See the last 7 days and the current streak of days the goal was met.
- Millilitres or US fluid ounces.
- Works offline, data stays on the phone, no account.
- Free with small, non-intrusive ads.
